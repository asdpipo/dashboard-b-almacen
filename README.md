# Dashboard B · Ingeniería del almacén — C3 y C4

## Contenido
- `index.html`: entrada para GitHub Pages; contiene el Dashboard B íntegro.
- `assets/c3/*.webp`: 7 ilustraciones de sistemas + 6 ilustraciones de equipos.
- `Dashboard_B_Ingenieria_Almacen_C3_C4.html`: copia del dashboard con nombre descriptivo.

## Publicar en GitHub Pages
1. Crea un repositorio público en GitHub, por ejemplo `dashboard-b-almacen`.
2. **Extrae este ZIP** antes de subirlo. En la raíz del repositorio deben quedar `index.html` y la carpeta `assets`.
3. Abre el repositorio > Add file > Upload files, arrastra `index.html`, `Dashboard_B_Ingenieria_Almacen_C3_C4.html`, `README.md` y la carpeta `assets` (o usa el navegador de carpetas de tu sistema). Confirma con Commit changes.
4. Ve a Settings > Pages > Build and deployment > Deploy from a branch; selecciona `main` y `/(root)` y pulsa Save.
5. Cuando se publique, visita `https://TU_USUARIO.github.io/dashboard-b-almacen/`.

## Alcance metodológico
- Datos cuantitativos C3/C4: del Excel del caso integrador.
- Ilustraciones: conceptual / generadas, **no reemplazan ficha técnica ni validación**.
- Circulación C4: 120 m² contabilizados una sola vez, representados como superficie distribuida, no como sala aislada.
- Layout y simulador son esquemáticos, no certifican factibilidad física.
